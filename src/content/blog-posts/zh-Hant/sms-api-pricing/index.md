> **tl;dr** — SMS API 定價按發送的每則訊息計費，並依**收件人的國家**定價，但帳面費率只是帳單的一部分。你的實際成本是目的地費率**加上**電信商附加費、A2P 註冊費、長訊息的多區段費用，以及 SMS pumping 的詐騙稅。

如果你透過 SMS 發送一次性密碼（OTP），這張發票可能會讓你嚇一跳。費率表寫著「每則 $0.05」，你動筆算了一下，結果真正的帳單卻更高——有時高得多。這篇指南拆解 SMS API 定價實際包含哪些成本，讓你能預測支出、揪出隱藏成本，並判斷改用更便宜的通道是否划算。

## SMS API 定價實際包含哪些成本

當你透過 Twilio、Vonage、Bird 或 Plivo 這類供應商發送 SMS 時，你付的是一連串轉手的費用。每一環都會增加成本。

- **目的地費率。** 這是最大的一項。每個國家的電信商都會收取終端費，才會把訊息投遞給他們的用戶，而供應商會把這筆費用轉嫁給你。各國費率差異極大——發送到泰國的成本只是發送到印尼的一小部分。
- **電信商／營運商附加費。** 在許多市場，供應商會報一個基礎發送費率，然後再另外加一筆電信商附加費，以獨立項目計費。帳面上的數字並不是你實際付的數字。
- **A2P 註冊與合規費用。** Application-to-person（A2P）訊息——包含 OTP 在內——是受監管的。視市場而定，你在能夠發送之前，可能要付一次性或每月費用來註冊你的品牌、活動或 sender ID。
- **訊息區段。** 在標準 GSM-7 編碼下，SMS 以每 160 字元為一個區段計費；但若訊息含有 emoji 或非拉丁文字等非 GSM 字元，則每個區段只有 70 字元。一則你看起來像「一則簡訊」的訊息，可能被計為兩到三個區段。
- **詐騙稅。** SMS pumping（簡訊泵送詐騙，也稱 AIT 或 toll fraud）利用機器人觸發大量 OTP 發送到攻擊者可從中獲利的付費號碼。每一則你都要付錢。我們在 [什麼是 SMS Pumping 攻擊？](/zh-hant/post/sms-pumping-attack) 中有深入說明。

## 推高你帳單的隱藏成本

基礎費率是你看得到的部分。真正讓團隊措手不及的，是那些不在報價上的成本：

- **電信商附加費** 在好幾個市場可能在基礎費率之上加上可觀的附加費，而且往往要等到收到發票才會顯示出來。
- **A2P 註冊** 在你還沒發送任何訊息之前，就可能加上固定的每月成本，尤其是在美國（10DLC）以及愈來愈多其他受監管的市場。
- **失敗投遞你仍要付費。** 在某些路由設定下，就算訊息從未送達，你也會被計費——在送達率不佳的市場，這是個實際存在的問題。
- **SMS pumping 詐騙** 可以在一夜之間灌爆帳單。由於攻擊者能從電信商終端費中分一杯羹，他們有直接的誘因狂打你的 OTP 端點。

## 如何降低你的 SMS 成本

你不必照單全收這張帳單。以下是幾個著力點，大致依影響力排序：

1. **OTP 優先走 WhatsApp，SMS 作為備援。** 這能為大多數用戶抓住上述的節省，同時仍然觸及每一個人。
2. **降低回訪用戶的 OTP 用量。** Passkey 與生物辨識登入在受信任的裝置上完全跳過 OTP，因此你不必再為最活躍的用戶每次登入付費。
3. **保護發送端點。** 速率限制與機器人偵測能把 SMS pumping 流量擋在你的帳單之外。
4. **依國家挑選合適的供應商。** 如表所示，最便宜的供應商因目的地而異。如果你大量發送到某個地區，路由就很重要。
5. **在投入之前先做試算。** 用你真實的用量與目的地來估算支出，而不是依賴單一平均值。如果你正在比較供應商，[Twilio Verify 定價與替代方案](/post/twilio-verify-pricing-and-alternatives) 與 [Twilio 替代方案：SMS 與 OTP 轉換指南](/zh-hant/post/twilio-alternatives) 都是實用的參考。

要自己把這一切都建起來，是一個實實在在的工程專案：WhatsApp 優先搭配 SMS 備援的路由、對回訪用戶降階到 passkey，以及發送端點的機器人防護。像 [Authgear](https://www.authgear.com) 這類驗證平台開箱即提供這些功能，包含 WhatsApp OTP 與自動 SMS 備援、用來降低 OTP 用量的 passkey 與生物辨識登入，以及內建的 SMS pumping 防護。在你改動任何東西之前，都可以先 [用 SMS 成本計算器估算你的節省](/zh-hant/tools/sms-cost-calculator)。

## 常見問題

### 透過 API 發送一則 SMS 要多少錢？

這幾乎完全取決於目的地國家。在主流供應商上，一則訊息的費用從泰國等低成本市場約 $0.03，到印尼等高成本市場的 $0.36 以上不等。美國的費率異常地低（在 Twilio 上約每則 $0.0083），但另外要收 A2P 註冊費。每則訊息的費率只是基礎；電信商附加費往往還會加在上面。

### 為什麼 SMS API 定價這麼貴？

有三項因素層層疊加：電信商為投遞訊息收取的終端費（各國差異極大）、A2P（application-to-person）註冊與合規費用，以及 SMS pumping 詐騙（簡訊泵送詐騙）——它用真實用戶從未要求過的訊息灌爆你的用量。長訊息還會被拆成多個計費區段。

### SMS 費率之上的電信商附加費是什麼？

許多供應商會報一個基礎發送費率，然後再另外加一筆「carrier fee」（電信商附加費）：這是目的地電信商收取、供應商代收轉付的費用。它以獨立項目計費，因此在好幾個國家，你每則訊息的實際成本會高於帳面費率。

### WhatsApp OTP 比 SMS 便宜嗎？

在大多數 SMS 成本高的市場，是的，每則往往便宜 40–90%，而且 WhatsApp 不會暴露在 SMS pumping 詐騙之下。取捨在於觸及範圍：收件人需要安裝 WhatsApp，因此你會保留 SMS 作為備援，服務那些沒安裝的少數人。

### 我要如何估算我的 SMS OTP 成本？

把你每月的 OTP 用量乘以每個目的地國家的每則費率，再加上電信商附加費與任何 A2P 註冊成本。我們的免費 [SMS 成本計算器](/zh-hant/tools/sms-cost-calculator) 會涵蓋 Twilio、Bird 與 Plivo 幫你算出這些，並把 WhatsApp OTP 的替代方案並排顯示。
